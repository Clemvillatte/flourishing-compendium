A soundscape player for long study sessions

FCPlayer is an adaptive soundscape player built for The Flourishing Compendium. It plays an ordered set of 60-second AAC segments back to back, gaplessly, with a designed loop fade, track selection, random jump, session timers and an optional circadian filter that warms and dims the sound late at night.

Try it

Use the round button in the bottom-right corner. The demo below plays a procedurally synthesized ambient set (8 segments, 8 minutes).

Prefer your own audio? — they stay on your device, nothing is uploaded.

How it works

The engineering design in brief — the full report lives in docs/DESIGN.md:

  • Segment-based playback. A soundscape is an ordered list of 60-second AAC segments. Each segment is fetched, decoded, and scheduled on the Web Audio timeline, so joins are sample-accurate.
  • Lookahead scheduling. A small scheduler keeps the next segments decoded and queued ahead of the playhead; if loading falls behind, the timeline is rebased and playback resumes after a short buffering gap.
  • Designed transitions. The final segment fades out before the set loops back to the first segment's natural intro. Track jumps and random picks use the same transition language.
  • Time-of-day adaptation. An optional circadian filter applies a gentle low-pass and level trim that follows the hour of day — brighter mid-day, warmer at night.

Controls

  • Select — pick any track from the list; playback jumps there.
  • Random — jump to a random track.
  • Play / Pause / Resume / Stop — full transport control; pause preserves the exact position.
  • Timer — 15/25/45-minute study timers with a gentle fade-out at the end.
  • Volume and the OS media keys (MediaSession) work as expected.

Integrate into the wiki

Two lines in site/index.html:

<link rel="stylesheet" href="assets/player/fc-player.css">
<script src="assets/player/fc-player.js" defer></script>

Then mount it once:

FCPlayer.mount({ title:'Focus Soundscape', subtitle:'study set · 16 min', source:{ dir:'assets/audio/segments/', pattern:'segment_%04d.aac', count:16 } });
