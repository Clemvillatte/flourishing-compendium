Transactive memory is the shared memory system a group develops by dividing the remembering: each member comes to hold some domains and, just as important, everyone comes to know who knows what. Daniel Wegner gave the concept its full theoretical shape in his 1987 chapter "Transactive Memory: A Contemporary Analysis of the Group Mind". ([Wegner 1987, opened chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "A transactive memory system is a set of individual memory systems in combination with the communication that takes place between individuals (Wegner, Giuliano, & Hertel, 1985)." (Wegner 1987, chapter 9, [opened carrier](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "The transactive memory system in a group involves the operation of the memory systems of the individuals and the processes of communication that occur within the group." (same source)

The system is genuinely collective rather than a mere sum of member memories: what each person can retrieve depends on what others hold and on the transactions between them. A couple in which one partner keeps the calendar and the other keeps the repair schedule has a transactive memory, and so does a team in which the members know which colleague holds which expertise.
