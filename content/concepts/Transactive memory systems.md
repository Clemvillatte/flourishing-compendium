Wegner describes a transactive memory system as individual memory systems combined with communication between people. ([Wegner's chapter](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "A transactive memory system is a set of individual memory systems in combination with the communication that takes place between individuals (Wegner, Giuliano, & Hertel, 1985)." (Wegner 1987, chapter 9, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "The transactive memory system in a group involves the operation of the memory systems of the individuals and the processes of communication that occur within the group." (Wegner 1987, chapter 9, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

The chapter revives an old question, the group mind, with the tools of individual cognition research: groups process and structure information, and the interesting unit of analysis is the group. Transactive memory is not traceable to any individual alone, Wegner argues; it is a constructed system, built up over time as members learn who is good at what. Once the group knows its experts, responsibility for new information follows the expertise.

> "Known experts in a domain are usually held responsible for the encoding, storage, and retrieval of any new information encountered in that domain." (Wegner 1987, chapter 9, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

The everyday version is a household. One partner keeps track of appointment dates, the other of repair arrangements; each asks the other rather than keeping both lists. The pair's memory, taken as a whole, holds more than either head alone, and leaning on that division is itself a small skill. Breaking up, Wegner notes, is likely to reduce the memory capabilities of both partners, and much of the grief that comes with the end of a close relationship can be traced to that loss.

> "The loss of transactive memory feels like losing a part of one's own mind." (Wegner 1987, chapter 9, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))
