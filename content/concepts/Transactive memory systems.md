Wegner describes a transactive memory system as individual memory systems combined with communication between people. ([Wegner's chapter](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "A transactive memory system is a set of individual memory systems in combination with the communication that takes place between individuals (Wegner, Giuliano, & Hertel, 1985)." (Wegner 1987, chapter 9, p. 186, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "The transactive memory system in a group involves the operation of the memory systems of the individuals and the processes of communication that occur within the group." (Wegner 1987, chapter 9, p. 191, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

The chapter revives an old question, the group mind, with the tools of individual cognition research: Wegner examines how groups and individuals process and structure information ([chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf)). Transactive memory is not traceable to any individual alone, Wegner argues; it is a constructed system, built up over time as members learn who is good at what. Members recognised as experts are usually expected to handle new information in their area.

> "Known experts in a domain are usually held responsible for the encoding, storage, and retrieval of any new information encountered in that domain." (Wegner 1987, chapter 9, p. 192, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

The everyday version is a household. One partner keeps track of appointment dates, the other of repair arrangements; each asks the other rather than keeping both lists. Each partner needs to know where information can be found and how to retrieve it through conversation. Wegner proposes that separation may impair both partners' remembering, because they lose access to the information and retrieval cues the other person supplied; he presents this as a possible contributor to the grief and disorientation that follow the end of a close relationship ([chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf), pp. 200-201).

> "The loss of transactive memory feels like losing a part of one's own mind." (Wegner 1987, chapter 9, p. 201, [chapter PDF](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))
