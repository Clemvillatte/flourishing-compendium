Wegner describes a transactive memory system as individual memory systems combined with communication between people. ([Wegner's chapter](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "A transactive memory system is a set of individual memory systems in combination with the communication that takes place between individuals (Wegner, Giuliano, & Hertel, 1985)." (Wegner 1987, chapter 9, [opened carrier](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%20Transactive%20Memory.pdf))

> "The transactive memory system in a group involves the operation of the memory systems of the individuals and the processes of communication that occur within the group." (same source)

This definition includes both individual remembering and communication within the group.

Imagined example: one partner remembers appointment dates and another remembers repair arrangements; they ask each other for the information.
