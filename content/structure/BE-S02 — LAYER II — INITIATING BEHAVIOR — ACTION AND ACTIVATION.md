These principles cover how to initiate behaviour: starting, activating, and building action.


## Principles

- [[BE013 — Learn behavioural activation — do it even when you do not feel like it]]
- [[BE014 — Learn to use activity scheduling — plan specific activities at specific times]]
- [[BE015 — Learn to use graded task assignment — break tasks into achievable steps]]
- [[BE016 — Learn to use the just 5 minutes technique — lower the barrier to starting]]
- [[BE017 — Learn to schedule valued activities — meaning-driven behaviour]]
- [[BE018 — Learn to schedule mastery activities — competence-driven behaviour]]
- [[BE019 — Learn to schedule pleasurable activities — enjoyment-driven behaviour]]
- [[BE020 — Learn to use behavioural experiments — test beliefs through action]]
- [[BE021 — Learn to use behavioural rehearsal — practise before performing]]
- [[BE022 — Learn to use opposite action — do the opposite of what the emotion urges]]
- [[BE023 — Learn to use shaping — build complex behaviours from small components]]
- [[BE024 — Learn to use chaining — link behaviours into sequences]]
