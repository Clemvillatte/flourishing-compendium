These principles address specific difficult emotions: fear, anxiety, anger, sadness, shame, guilt, envy, disgust, and boredom. Each has a distinct function, a distinct failure mode, and a distinct adaptive response.


## Principles

- [[AF047 — Understand fear's function — it prepares you for threat]]
- [[AF048 — Recognise anxiety's core — intolerance of uncertainty]]
- [[AF049 — Learn to work with panic — panic is fear of fear]]
- [[AF050 — Understand anger's function — it signals a violated boundary or blocked goal]]
- [[AF051 — Recognise the difference between sadness and depression]]
- [[AF052 — Learn to grieve — grief is a process, not a problem to solve]]
- [[AF053 — Work with shame — it is about the self, not the act]]
- [[AF054 — Recognise guilt's adaptive function — it motivates repair]]
- [[AF055 — Work with envy — it signals a value, not a defect]]
- [[AF056 — Recognise disgust's function — it protects from contamination]]
- [[AF057 — Work with boredom — it is a signal, not a void to fill]]
- [[AF058 — Recognise loneliness — it is a signal, not a character flaw]]
- [[AF059 — Work with disappointment — it is the gap between expectation and reality]]
- [[AF060 — Recognise compassion fatigue — empathy has limits]]
