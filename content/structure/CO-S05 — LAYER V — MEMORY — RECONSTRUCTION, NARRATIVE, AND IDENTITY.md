These principles cover how memory works and how to use it well.


## Principles

- [[CO053 — Recognise that memory is reconstructive, not reproductive]]
- [[CO054 — Understand that memory is state-dependent — mood and context affect recall]]
- [[CO055 — Know that memories can be implanted — confidence is not accuracy]]
- [[CO056 — Use memory deliberately — encoding and retrieval matter]]
- [[CO057 — Recognise the peak-end rule in memory — you remember peaks and endings]]
- [[CO058 — Understand flashbulb memories — vividness is not accuracy]]
- [[CO059 — Recognise rosy retrospection — the past is remembered more fondly than it was experienced]]
- [[CO060 — Use memory for growth — reconsolidation allows updating]]
- [[CO061 — Recognise the role of narrative in identity — your life story shapes who you are]]
- [[CO062 — Understand autobiographical memory specificity — specific memories are healthier than general ones]]
