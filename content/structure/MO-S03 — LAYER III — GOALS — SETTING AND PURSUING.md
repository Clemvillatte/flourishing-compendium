These principles cover goal setting and pursuit: how to set effective goals and follow through.


## Principles

- [[MO023 — Set specific and difficult goals — vagueness kills motivation]]
- [[MO024 — Learn to break goals into subgoals — small wins sustain motivation]]
- [[MO025 — Learn to use implementation intentions — if-then plans]]
- [[MO026 — Learn to use mental contrasting — visualise obstacle, not just outcome]]
- [[MO027 — Learn to make progress visible — feedback sustains motivation]]
- [[MO028 — Learn to use the fresh start effect — temporal landmarks boost motivation]]
- [[MO029 — Learn to use temptation bundling — pair unpleasant tasks with pleasures]]
- [[MO030 — Learn to reduce friction for desired behaviours — make it easy]]
- [[MO031 — Learn to increase friction for undesired behaviours — make it hard]]
- [[MO032 — Learn to commit publicly — accountability sustains motivation]]
- [[MO033 — Learn to use commitment devices — pre-commit to future behaviour]]
- [[MO034 — Learn to review and adjust goals — flexibility matters]]
