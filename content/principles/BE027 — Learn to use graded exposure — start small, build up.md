> **Principle 27** — Learn to use graded exposure: start small, build up

Graded exposure involves creating a hierarchy of feared situations (from least to most feared) and approaching them in order, starting with the easiest. This makes exposure manageable.

**Plain words** Build a ladder of feared situations and climb it from the bottom — least scary first, one rung at a time. The aim is a different relationship with the fear, not its disappearance. For significant anxiety, build the ladder with a clinician.

*For example:* The socially anxious person's hierarchy: coffee with one friend → small gathering → the work party. Each rung is a data point — "I did it" — and the data, not the fear level, is what counts.

## Practice

- Create a fear hierarchy: list feared situations from least to most frightening. Start with the easiest, approach it repeatedly until anxiety decreases, then move up. Do not start with the hardest.
