> **Principle 66** — Learn to use technology deliberately: not all technology is attentional enemy

Technology is not inherently attentional enemy. Some technologies (writing, reading, focused work tools, meditation apps, calendars) support attention. The skill is deliberate use rather than passive consumption.

**Plain words** Technology isn't the enemy — undeliberated technology is. A dumb keyboard, an e-reader, a timer: tools that serve focus. The test is simple: does this tool spend my attention, or invest it?

*For example:* The e-ink reader that does nothing but read — you finish chapters. Same eyes, same words, different machine. The device's intent matters.
## Psychology parallels

- **Technology design can support or undermine attention**, attentional design principles can be applied to support focus (Fogg, 2003; Eyal, 2014)
- **Deliberate vs habitual technology use**, intentional use is associated with better well-being than habitual use (Valkenburg et al., 2022; Orben & Przybylski, 2019)

## Philosophy parallels

- **The tool is neutral; the use is moral** (Aristotle, Nicomachean Ethics)
- **[[Right livelihood|Right livelihood includes right technology]]** (Buddhism, Eightfold Path)
- **Pragmatism: use what works** (James, Pragmatism)

## Practice

- Use technology deliberately: choose tools that support focus (writing, calendar, focused apps), avoid tools designed for infinite engagement (infinite scroll, autoplay), and set intentions before use.
