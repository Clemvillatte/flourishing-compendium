> **Principle 59** — Know the obstacles by name

The tradition lists nine: illness, mental inertia, doubt, heedlessness, laziness, craving, false perception, failure to gain ground, and instability in attainment. The list is diagnostic gold, because each obstacle has a different remedy, and misdiagnosis wastes months: doubt is not laziness, and instability is not failure of ground. Practically, when practice stalls, name the obstacle before adjusting anything.

(YS 1.30.)

**Plain words** The nine obstacles, by name: illness, mental inertia, doubt, heedlessness, laziness, craving, false perception, failure to gain ground, instability in attainment. Each has a different remedy, and misdiagnosis wastes months — doubt is not laziness. Learn the list; use it.

*For example:* Someone treats their practice stall as laziness and applies discipline — more effort, more hours — and gets worse. The actual obstacle was doubt, which needs evidence, not effort. The list would have caught it in a minute.
