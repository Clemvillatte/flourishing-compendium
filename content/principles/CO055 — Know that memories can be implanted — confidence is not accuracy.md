> **Principle 55** — Know that memories can be implanted: confidence is not accuracy

False memories — vivid, detailed, confidently held memories of events that never happened — can be created through suggestion, imagination, and social pressure. Confidence in a memory is not evidence of its accuracy.

**Plain words** False memories — vivid, detailed, confidently held memories of events that never happened — can be created through suggestion, imagination, and social pressure. Confidence is not evidence. Your most vivid memory is a feeling, not a recording.

*For example:* The family story about the trip that the older sibling "remembers clearly" — until the photo album dates it three years before they were born. The vividness was real; the event was borrowed. Every courtroom and every family dinner runs on these.
## Psychology parallels

- **[[False memory implantation (Loftus)|False memory implantation (Loftus)]]**, suggestive techniques can create detailed false memories (Loftus & Pickrell, 1995; Shaw & Porter, 2015)
- **[[Misinformation effect|Misinformation effect]]**, exposure to misleading information after an event alters memory for the event (Loftus & Palmer, 1974; Loftus, 2005)
- **Confidence does not equal accuracy**, memory confidence is weakly related to memory accuracy (Wells et al., 2000)

## Practice

- Do not treat vividness or confidence as evidence of accuracy. When a memory is important (for a decision, a judgment, a legal matter), seek external corroboration.
