> **Principle 28** — Learn to use the fresh start effect: temporal landmarks boost motivation

Temporal landmarks (new year, birthday, Monday, first of the month) create a sense of a "new beginning" that boosts motivation and goal initiation. Using these landmarks deliberately increases goal pursuit.

**Plain words** Temporal landmarks — new year, birthday, Monday, first of the month — give the mind a "clean page" feeling, and motivation genuinely spikes. Use them shamelessly: start things on landmarks. The fresh-page feeling is real; ride it.

*For example:* The gym packed every January and the same gym quiet every March — the landmark works; the follow-through needs the rest of this list. But never start on a random Wednesday what you could start on the first.
## Psychology parallels

- **[[Fresh start effect (Dai et al.)|Fresh start effect (Dai et al.)]]**, temporal landmarks increase goal initiation and motivation (Dai et al., 2014; Peetz & Wilson, 2008)
- **New beginnings and aspirational behaviour**, landmarks increase the likelihood of starting new goals (Dai et al., 2014; Sullivan & Rothman, 2017)

## Philosophy parallels

- **[[Metanoia (transformation)|Metanoia: the turning]]** (Christian tradition)
- **The new day** (Stoics, Marcus Aurelius, Meditations)
- **Begin again** (Zen Buddhism, Suzuki)

## Practice

- Use temporal landmarks: start goals on Monday, the first of the month, your birthday, or the new year. Treat these as fresh starts. The "new beginning" framing boosts motivation.
