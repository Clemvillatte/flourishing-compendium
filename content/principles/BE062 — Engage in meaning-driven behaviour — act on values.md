> **Principle 62** — Engage in meaning-driven behaviour: act on values

Meaning-driven behaviour — acting on what you value (justice, creativity, connection, growth, contribution) — is a specific behavioural practice. It connects behaviour to values and provides purpose.

**Plain words** Values-driven behaviour — acting on justice, creativity, connection, whatever yours are — is the difference between being busy and being on course. The calendar is the real statement of values; audit it.

*For example:* "Family is everything" says the calendar with zero family dinners this month — the value is real; the behaviour is the missing evidence. Book the dinner. That's the value becoming true.
## Psychology parallels

- **[[Values|Values-based committed action (ACT)]]**, acting on values is the core behavioural process (Hayes et al., 2011; Wilson et al., 2010)
- **Meaning and behaviour**, meaning-driven behaviour predicts well-being (Steger, 2012; Martel et al., 2001)

## Philosophy parallels

- **[[Eudaimonia|Eudaimonia as virtuous activity]]** (Aristotle, Nicomachean Ethics)
- **[[Right action serves right view|Right action serves right view]]** (Buddhism)
- **[[Values|Values as action]]** (Socrates, Apology)

## Practice

- Engage in meaning-driven behaviour: identify values and act on them. If you value justice, act justly. If you value creativity, create. If you value connection, connect. Values without action are empty.
