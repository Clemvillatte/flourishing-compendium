> **Principle 65** — Build a portfolio, not a single practice

No single practice produces flourishing. The approach that works is a portfolio: a set of practices that target different dimensions of well-being (emotion, engagement, meaning, relationship, accomplishment), adapted to the person, the context, and the season of life. The portfolio should be reviewed regularly: which practices are earning their place? Which have gone stale? Which need to be retired or varied?

(Schueller, 2014; Parks et al., 2012.)

**Plain words** No single practice produces flourishing. Build a portfolio that covers different dimensions: emotion, engagement, relationships, meaning, accomplishment. Review it regularly and rebalance.

*For example:* One person's week includes running, dinner with a friend, hard work on a craft and an evening of quiet.
