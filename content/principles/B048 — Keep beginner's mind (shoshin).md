> **Principle 48** — Keep beginner's mind (shoshin)

Approach each sitting, each day, each person, as if for the first time. In the beginner's mind are many possibilities; in the expert's, few.

(Suzuki, Zen Mind, Beginner's Mind.)

**Plain words** Approach each sitting, each day, each person as if for the first time. In the beginner's mind are many possibilities; in the expert's, few. Expertise is a gift that keeps taking — it takes the freshness off everything it touches.

*For example:* The twenty-year marriage that stays warm does it by occasionally meeting a stranger at breakfast — same person, beginner's eyes.

## Psychology parallels

- **[[Growth mindset|Growth mindset]]**, beliefs about malleability shape persistence (Dweck, 2006; effect sizes vary by context)
- **[[Openness|Openness to experience]]**, the trait most associated with beginner's reception (McCrae and Costa, 1997)

## Philosophy parallels

- **[[Socratic ignorance|Socratic ignorance]]** (Plato, Apology)
- **[[To the things themselves|The return to the things themselves]]** (Husserl, Ideas I)
