> **Kernel K330** — Value-creation audit

List the values you currently live by. For each, ask: Did I choose this, or did I inherit it? Does it still serve my flourishing? The audit is Nietzsche's question: which values are life-affirming and which are inherited dead weight? The exercise is not about rejecting inherited values but about taking responsibility for them. Research on value congruence shows that alignment between stated and lived values predicts well-being.
