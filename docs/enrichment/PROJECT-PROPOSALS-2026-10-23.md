# Project proposals — strategic session 2026-10-23

Written by supervisor-pplx-1023a for owner review. Each proposal serves the mission
directly: essays on genuine flourishing, alleviation of suffering, wisdom development.
All are buildable on existing structures (bands, protocols, validators) and existing
verified content; none requires new infrastructure beyond one small script or a new
content type.

## 1. Essay dossiers (recommended first)

A dossier is a one-page compilation FOR THE OWNER'S ESSAYS: given a theme
(suffering, attention, forgiveness, luck, anger...), a script assembles the wiki's
material on it — matching principles with their verbatim quotes and locators,
concepts, thinkers, workable kernels, stories and sayings — each entry linked and
already source-verified. The wiki's content becomes a research desk rather than a
reference the owner re-searches by hand.

- Form: generated markdown per theme (content/dossiers/ or a private docs/ folder;
  owner choice whether to publish).
- Effort: one script (reuses the build.py link graph) + a theme list. Days, not weeks.
- Risk: none — read-only compilation of verified content.

## 2. Disagreement dossiers (cross-tradition spines)

The wiki holds genuine cross-tradition disagreements in its body already: self
(anatta vs atman), desire (tanha vs desire-as-spanda), effort (wu wei vs discipline),
the mean vs the extreme, attachment (nonattachment vs bonded love). A disagreement
dossier is a structured MOC that quotes EACH position verbatim from an opened carrier
with locators, then maps which principles/concepts/thinkers carry each side. Highest
essay value of the proposals: the owner's essays argue positions; these pages give the
argued positions with receipts.

- Form: new pages under content/concepts/ with a 'disagreement' tag (validator bar
  applies; every quote opened in-session per the standing rule).
- Effort: a band of ~12-20 dossiers; one item ≈ one concept item.
- Risk: low — scope strictly to disagreements the corpus already supports; no invented
  syntheses.

## 3. Quotation provenance index

Corpus-wide inventory: every quoted fragment → its carrier URL, locator, verification
status and last-verified date, as a generated data file (updated by build.py or a
dedicated script reading the band ledgers and QC log). Makes the zero-hallucination
guarantee auditable, makes re-verification cheap (the QC log shows the recurring
defect classes: inserted words, flattened dashes, normalized punctuation), and gives
the owner a single place to see what is certified.

- Effort: one script + a backfill pass reading existing ledgers. The backfill is
  honest work (the index starts with what is recorded, not with claims).
- Risk: none — read-only.

## 4. Practice pathways (workable arcs)

Sequenced 4-8 step arcs that string EXISTING kernels into a course of practice:
"working with anger" (recognition → labeling → de-escalation → repair), "beginning a
practice" (posture → breath → counting → returning), each step a link to an existing
kernel with its PBT/dimension notes. The owner's workability directive (2026-10-21)
made single kernels workable; pathways make the corpus usable as a curriculum.

- Form: new pages (content/pathways/ or concept-type with a tag), each step
  linking existing kernels only — no new unverified claims.
- Effort: a band; one item ≈ one concept item but with mostly-existing links.
- Risk: low — sequencing claims must stay practical, not clinical.

## 5. Thinker reciprocal integration (t2a)

Complete the owner's "exhaustively interconnected" directive: a band that reviews
the 3,946 reciprocal proposals per-page and applies the clearly-supported ones

T007 ruling). Phased by thinker, highest-degree first. Also mints the extension
thinkers (T038-T048) if the owner signs the proposal in
thinkers-extension-proposal.md.

- Effort: multi-band; the review is the work (the proposals exist).
- Risk: medium — must stay per-page contextual; the standing no-wholesale-apply
