  https://www.gutenberg.org/files/2680/2680-h/2680-h.htm
  - NOTE (advisor QC correction, A004 milestone): the first draft attributed this to George

    world is as it were a city."

    detached from the community."
  - Supported ("HOW MAGNANIMITY IS CONSISTENT WITH CARE", = Discourses II.5): "For what is
    a man? A part of a state, of that first which consists of gods and of men; then of that
    which is called next to it, which is a small image of the universal state."
