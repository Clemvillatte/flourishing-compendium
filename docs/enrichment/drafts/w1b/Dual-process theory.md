Dual-process theory, in the form defended by its leading theorists, distinguishes autonomous Type 1 processing from Type 2 processing that depends on working memory and supports hypothetical reasoning. The canonical review's summary: "Our preferred theoretical approach is one in which rapid autonomous processes (Type 1) are assumed to yield default responses unless intervened on by distinctive higher order reasoning processes (Type 2). What defines the difference is that Type 2 processing supports hypothetical thinking and load heavily on working memory" ([Evans & Stanovich 2013, Perspectives on Psychological Science](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)). The authors allow that multiple cognitive or neural systems may underlie each processing type.

### What defines each

Type 1's defining characteristic is autonomy: these processes run without controlled attention and so make minimal demands on working memory resources ([Evans & Stanovich 2013](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)). Their execution tends to be rapid and associative, but the authors stress that these correlated features are not defining ([Evans & Stanovich 2013](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)). Type 2 requires working memory and is marked by "cognitive decoupling; mental simulation": "In order to reason hypothetically, we must be able to prevent our representations of the real world from becoming confused with representations of imaginary situations" ([Evans & Stanovich 2013](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)).

### The architecture and its cautions

Evans and Stanovich favour a default-interventionist architecture: "fast Type 1 processing generates intuitive default responses on which subsequent reflective Type 2 processing may or may not intervene" ([Evans & Stanovich 2013](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)). One caution travels with the theory's fame: the authors "have recently discontinued and discouraged the use of the labels System 1 and 2," since System 1 is really a plural, "a set of systems in the brain" ([Evans & Stanovich 2013](http://keithstanovich.com/Site/Research_on_Reasoning_files/Evans_Stanovich_PoPS13.pdf)). Kahneman's Thinking, Fast and Slow made the system names famous; the careful form is Type 1 and Type 2 processing.

### A different dual process

The label also names a different model in grief research. There, in the dual process model of coping, "healthy people oscillate between focusing on loss-related stressors... and restoration-related stressors... and at other times are simply engaged in everyday life experience" ([O'Connor 2019 review, PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC6844541/)). That is a pairing of grief orientations, not an application of Type 1 and Type 2 processing.

### In the compendium

CO002 names the two modes for practice: fast intuition and slow analysis. The compendium pairs the theory with Cognitive defusion, Metacognition, and Cognitive reappraisal as editorial neighbours, without assigning those practices to processing types.
