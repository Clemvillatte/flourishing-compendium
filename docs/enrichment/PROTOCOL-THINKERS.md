## Purpose

A Thinker page is a Map of Content (MOC) for one person whose ideas the wiki
already draws on: it holds the person's story and motivation, states their
position, lists their core ideas, and — most importantly — inventories
exhaustively everything in the corpus that connects to them. The owner's
directive (2026-10-22): "the Thinkers pages... should be exhaustively
interconnected on the graph." Interconnection is bidirectional: the thinker
page links to every corpus entry that names them, and those entries link back.

## Who qualifies

A thinker gets a page when the corpus already leans on them repeatedly:
rule of thumb, named in 10+ entries across principles/concepts/kernels/
stories/sayings, or a clearly central source (owner's primary-source library,
PRIMARY-SOURCES.md). Do not mint pages for people with only passing mentions.

## File and frontmatter schema

Directory: `content/thinkers/`. Filename: `T001 — Last name, First name.md`
(sequential ids; keep the display name in the file field).

```yaml
---
schema: 0
id: "T001"
type: "thinker"
title: "Csikszentmihalyi, Mihaly"
file: "T001 — Csikszentmihalyi, Mihaly"
tags: ["person", "track/psychology"]
navigation: {"track": "shared", "primaryPath": ["NAV-SHARED", "NAV-SHARED-THINKERS"], "alternatePaths": []}
legacy: {"volume": "Companion — Thinkers", "book": "Thinkers — A to Z", "chapter": "Letter C", "parent": ""}
---
```

Keep it minimal and consistent with the other schemas; `build.py` picks up any
file in `content/` with matching keys, so no builder change is needed.

## Page structure (fixed order)

1. `## Personal story / context` — 60–150 words. The biographical arc that
   explains the person, written from verified sources. Include one or two
   verbatim quotes from the person about their own life when available
   (primary-source rule applies: quote only what you actually opened).
2. `## Their why` — 40–100 words. The motivating question or wound. Humanise:
   plain words, no academic throat-clearing. Anchor in the person's own words
   where possible.
3. `## Their position` — 60–120 words. The stance they took, in plain terms.
4. `## Core ideas` — bulleted list. One bullet per core idea: **Bold name** —
   one-sentence gloss, then the wiki entries that carry that idea as
   `[[Title]]` wikilinks. This section is the MOC's spine.
5. `## Everything connected in the wiki` — the exhaustive interconnection
   inventory, generated by `scripts/thinker_links.py -t <Name>` and pasted
   in, grouped by node type (Principles / Concepts / Kernels / Stories /
   Sayings). Every entry listed here MUST exist (the script resolves titles
   to actual files, so it cannot hallucinate).
6. `## Sources` — the sources actually opened while writing the page, with
   URLs, so quotes are verifiable.

Word budget: 250–500 prose words total (excluding the interconnection list),
consistent with the wiki's density conventions.

## The interconnection engine (exhaustiveness guarantee)

`scripts/thinker_links.py`:
- `-t "Name"` scans all of `content/{principles,concepts,kernels,stories,
  sayings,thinkers}` for mentions of the name (first name or surname, with
  manual alias support), resolves each match to its real file/title, and
  prints a grouped inventory of outgoing links for the thinker page.
- `--reciprocal "Name"` emits a queue of proposed reciprocal links (entries
  that mention the thinker but do not yet link `[[Txxx — ...|Thinker name]]`),
  in the same format `enrich_validate.py` uses for proposed_reciprocal.
  Reciprocal links are applied only by the supervisor (or a thinker-band
  worker through the validate→apply path), never by editing another band's
  in-flight items.

## Pipeline

- New band: `thinkers` (baton kind `thinkers`, bands `t1a`, `t1b`, ...).
- Queue file: `docs/enrichment/queue-thinkers.json` (same schema as
  queue-concepts.json; each item = thinker name + score = corpus mention
  count + evidence links).
- Worker flow per thinker: run `thinker_links.py -t`, research the life via
  web (verified sources only), write the page, paste the generated inventory,
  validate with `enrich_validate.py` (the wiki-link targets all resolve by
  construction), save, then run `--reciprocal` and let the supervisor apply
  the backlinks.
- Mentions-count scores seed the queue: current top candidates include
  Aristotle, William James, Dewey, Nietzsche, Confucius, Epictetus, Seneca,
  Marcus Aurelius, the Buddha, Ryan & Deci, Bandura, Neff, Kahneman, Seligman.
  The exemplar (Csikszentmihalyi, 40 principles + 19 concepts) is done.

## Relation to Kernels

Kernels did not get a dedicated worker pipeline before now; the kpr band
existed but only ~19 kernels reached the K100 standard and K409 is still a
candidate exemplar. Plan (supervisor, 2026-10-22): kernels join the same
pipelined band machinery — `queue-kernels.json` scored by thinness (prose
word count below the K100 bar), a `k1a`-style baton, and the same
mint→enrich→validate→save loop, using K100 as the model exemplar. K100's
structure (lead sentence — When/How/What it operationalises with embedded
links) is the kernel format; the K409 "Most Successful Thinkers" items were
verified as compliant.

## QC bar (from PROTOCOL-PRINCIPLES, adapted)

- No hallucination: every fact and quote from a source actually opened.
- Plain words sections must read human, not template-replicate.
- Verbatim source quotes are a real plus.
- Every wikilink target must exist.
