# Degrees ecosystem taskboard

Routing for the Degree Rework. Workers append checkpoints at the top of
their section; supervisors append routed notes. Bands and mechanics are in
OPERATIONS.md.

## Launch plan (strategist, 2026-10-25)

Phases: Phase 0 (setup, in progress by the strategist), Phase 1
(multi-agent production), Phase 2 (gates and integration per degree).

1. Phase 0 closes when: scope docs for all nine degrees are verified by the
   degree owners against opened sources, the superskill is piloted on one
   theory module and one practice module, and the advisor has reviewed both
   pilots.
2. Phase 1 launch order: pilot degrees first (deg-philosophy as the theory
   pilot, deg-qigong as the practice pilot), then the remaining theory
   degrees (deg-mind, deg-wellbeing, deg-therapeutic, deg-relational,
   deg-contemplative), then deg-cmp (via the designated cmp agent per the
   2026-10-22 owner directive) and deg-psychology-101 (pending the owner's
   ruling on its fate).
3. The verification band (deg-verify) starts with the shared queue below
   as soon as Phase 0 closes, and keeps pace with new sources.

## Shared verification queue (deg-verify)

Re-verify the 291 "imported" sources to the skill's standard; each entry
moves from the queue to the owning degree's ledger as it is verified or
replaced. Claim a block of 10 by appending "(in progress: your-id)" beside
it. Priority: sources attached to modules in active degree bands first.

- Block A: deg-philosophy attached sources (12 items)
- Block B: deg-contemplative attached sources (15)
- Block C: deg-relational attached sources (11)
- Block D: deg-mind attached sources (12)
- Block E: deg-wellbeing attached sources (8)
- Block F: deg-therapeutic attached sources (8)
- Block G: deg-psychology-101 (1)
- Block H: unattached or mission-page leftovers (remainder of 291)
