# REA archive (research record — NOT part of the soundscape-player project)

This folder is a research record kept for provenance. It is intentionally
separate from `soundscape-player/`, whose documentation presents the
player as original engineering work.

- `FINDINGS.md` — the investigation report behind the segment-delivery
  design adopted by soundscape-player: how the reference system (a
  commercial soundscape app) delivers pre-mixed 60-second AAC segments
  over HLS with an ordered-playback client, what was verified (delivery
  mechanism, hour-keyed render interface, fade behavior) and what was NOT
  recovered (their composition/interweaving algorithm). Includes REA
  evidence IDs and verified source quotes.

The next agent does NOT need this archive or any reference-app access to
continue the project — all actionable findings are already distilled into
`soundscape-player/docs/DESIGN.md` and `docs/ROADMAP.md`. Raw REA
evidence files were not archived (reproducible from public sources; only
useful inside the REA tool itself).
